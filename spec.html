3. Concrete Forced Failure Trigger & Error Recovery Invariants

Named Trigger: #toggle-simulated-error in Top Navigation Bar
1 Toggle switch in toolbar to ON (simulateError = true).
2 Type "Plan my Kyoto weekend" and press Send.
3 Planner simulates 800ms loading dots, then rejects with simulated 503 HTTP error.
4 Inline error bubble renders with empathetic message and red "Try again" button inside.
5 Tap "Try again" → error clears and all 3 weekend cards render reliably.
⚠ Couldn't generate your Kyoto weekend plan
We had trouble connecting to the planner. Your request is safely saved.
↻ Try again
Recovery Guarantee: "Try again" retries query in-place without page reload. Zero blank chat states permitted.
